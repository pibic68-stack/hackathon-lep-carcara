# Matriz de barreiras (rascunho para a Pessoa 1 validar)

> Ponto de partida para acelerar a pesquisa, **não** é a versão final.
> Cada linha precisa de **fonte** antes de ir para o Manual. Marque ✅ quando validar.

## Referências para começar

- **Lei Brasileira de Inclusão** (Lei 13.146/2015): direito à educação inclusiva e às adaptações razoáveis
- **Política Nacional de Educação Especial na Perspectiva da Educação Inclusiva** (MEC, 2008)
- **AEE**: Atendimento Educacional Especializado, e o **PEI** (Plano Educacional Individualizado)
- **DUA / UDL**: Desenho Universal para a Aprendizagem (CAST). Planejar para todos desde o início
- **WCAG 2.2**: acessibilidade de conteúdo digital (contraste, cor, texto alternativo)
- Ponto a verificar: TDAH e dislexia são *transtornos funcionais específicos* e nem sempre são
  enquadrados legalmente como deficiência. Vale incluir mesmo assim, mas com essa ressalva.

## Matriz

| Necessidade | Barreiras típicas na escola | Adaptação do material | Adaptação da avaliação | Fonte | ✅ |
|---|---|---|---|---|---|
| **Cegueira** | Material só visual, imagens sem descrição, quadro | Texto compatível com leitor de tela, descrição de imagens, áudio, braile, materiais táteis | Prova oral ou em braile, tempo extra | | |
| **Baixa visão** | Letra pequena, baixo contraste, páginas poluídas | Fonte ampliada (≥ 18pt), alto contraste, menos elementos por página | Prova ampliada, tempo extra | | |
| **Daltonismo** | Informação passada só por cor (mapas, gráficos, correção em vermelho/verde) | Cor sempre com símbolo, padrão ou palavra | Evitar questões que dependam de distinguir cores | | |
| **Surdez / deficiência auditiva** | Aula só falada, vídeos sem legenda | Legendas, Libras, apoio visual, texto escrito das instruções | Enunciado claro e visual, intérprete de Libras | | |
| **TEA (autismo)** | Excesso de estímulos, instruções implícitas, mudanças sem aviso, linguagem figurada | Instruções em etapas, rotina visual, linguagem literal, layout limpo, antecipação | Ambiente calmo, enunciados diretos, uma tarefa por vez | | |
| **TDAH** | Tarefas longas, muitos estímulos, dificuldade de organização | Tarefas divididas em partes, checklist, destaque do essencial | Prova fracionada, pausas, tempo extra | | |
| **Dislexia** | Textos longos e densos, fontes difíceis, leitura em voz alta forçada | Fonte sem serifa, espaçamento maior, frases curtas, áudio | Leitura do enunciado, valorizar o conteúdo e não a ortografia | | |
| **Deficiência intelectual** | Conteúdo abstrato, linguagem complexa, ritmo único | Texto simplificado, exemplos concretos, imagens de apoio, mesmo tema em nível acessível | Avaliação pelo progresso individual (PEI) | | |
| **Deficiência física / motora** | Escrita manual, materiais difíceis de manipular, acesso ao espaço | Material digital, resposta por voz ou digitação, tecnologia assistiva | Formatos alternativos de resposta, tempo extra | | |

## Perguntas para a pesquisa responder

1. Quais são as **3 necessidades mais frequentes** nas matrículas (Censo Escolar / INEP)? Elas definem a demo.
2. O que o professor **já recebe hoje** de apoio (AEE, PEI)? Onde exatamente ele fica sem ajuda?
3. O que a família precisa saber **em linguagem simples**?
4. Quais sinais observáveis em sala justificam **encaminhar** a um profissional (sem diagnosticar)?
